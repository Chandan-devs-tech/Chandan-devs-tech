## Featured Projects

### AWS Bedrock AI Agent
Customer support agent built with Amazon Bedrock, Amazon Nova Micro model, TypeScript, and AWS SDK v3. Demonstrates multi-turn conversation memory and agentic patterns using the Converse API.
[View Repository](https://github.com/Chandan-devs-tech/bedrock-agent-demo)

### AI Job-Search Automation System
Self-hosted multi-agent platform running 24/7 on Oracle Cloud. Three agents handle job discovery and scoring, resume tailoring and email applications, and LinkedIn alert parsing. Fetches live jobs from 7 APIs, scores them with Gemini Flash LLM, and delivers daily reports via Telegram bot and email. Built with Python, LLM orchestration, cron, and systemd.

### Ask-My-Docs RAG System
Production RAG pipeline for document question answering. Uses sentence-transformers for embeddings, ChromaDB as the local vector database, and Gemini Flash as the answering model. Deployed on Oracle Cloud with a Telegram bot interface running 24/7 via systemd. Zero cloud spend.

### Piace.ai
Marketing site for an AI product. Built with TypeScript, Next.js, and Framer Motion.
[www.piace.ai](https://www.piace.ai)

### Chicago Indian Arts
Arts organization site with headless CMS (Payload) and media pipeline (Cloudinary). Built with Next.js 15, Tailwind v4, Framer Motion, and Lenis.
[chicagoindianarts.org](https://chicagoindianarts.org)
